# Светлана Демидович — наращивание и ламинирование ресниц

Готовый статический сайт. HTML, CSS, JavaScript, изображения и шрифты находятся в этом репозитории. Сборка и установка пакетов не нужны.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень публичного репозитория. Файл index.html должен быть в корне.
2. Откройте Settings → Pages.
3. Выберите Source: Deploy from a branch, Branch: main, Folder: / (root), затем Save.
4. Дождитесь завершения публикации. GitHub покажет рабочую ссылку на этой странице.

Сайт использует относительные пути и подходит для адреса вида https://имя.github.io/название-репозитория/.

## Обновления

Тексты находятся в index.html, оформление — в styles.css, фотографии и шрифты — в assets/. Ссылка на запись и фотографии галереи также заданы в site-config.js.

Оригиналы фотографий 3D и 2D сохранены и доступны из просмотра галереи. Лицензии шрифтов включены в assets/.
